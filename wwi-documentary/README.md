# WWI Documentary Project — codename **Verdun**

> A YouTube long-form documentary channel about **World War I**, where we use AI
> (Claude Code, Codex, Whisper, TTS, etc.) to **reverse-engineer the craft** of
> the best modern WWII documentaries — narration tone, pacing, story selection,
> emotional beats — and rebuild that *style* around original WWI content.
>
> We are copying the **method and feel**, never the script, footage, or voice.

## The one-sentence pitch

> "Hardcore History meets a Tom-Hanks-narrated streaming doc — but for the Great
> War, produced on an AI-assisted pipeline so one person can ship cinema-grade
> long-form."
